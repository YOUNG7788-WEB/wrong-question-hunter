# 🎯 AI 错题猎人 · Wrong-Question Hunter

> 把错题当成有血量的怪：录入 → 归类 → 按艾宾浩斯曲线追杀 → 彻底斩除。

一个**单文件、零依赖、纯离线**的错题管理工具。双击 `index.html` 就能用，不需要装任何东西，数据只存在你自己的浏览器里。

---

## 为什么做这个

传统的错题本有个致命问题：**抄完了就不会再看第二次**。

「错题猎人」用两个机制解决它：

1. **艾宾浩斯间隔重复** —— 到期未复习的错题会主动出现在「今日战场」，不用你自己记得翻
2. **游戏化血量系统** —— 一道题必须连续答对 3~4 次、把血量打到 0 才算「斩除」，杜绝"看答案觉得懂了"的幻觉

---

## 核心机制

| 自评 | 效果 | 下次复习 |
| :--- | :--- | :--- |
| ✔ **会了** | −45 HP，难度阶 +1 | 1→2→4→7→15→30→60 天 |
| 😐 **模糊** | −15 HP，阶数不变 | 明天 |
| ✘ **不会** | +30 HP（回血），打回第 1 阶 | 明天 |

初始血量按难度设定：**简单 100 / 中等 120 / 困难 150**。
血量归零 → **斩杀成功**，永久移入荣誉墙。

---

## 功能

- **今日战场** —— 到期错题排队等你，可先「揭示答案」再自评
- **录入猎物** —— 科目、知识点、难度、题目、错因、正确思路
- **错题图鉴** —— 按科目筛选 + 全文搜索，支持重置 / 删除
- **战报统计** —— 总数、斩杀率、连续打卡天数、各科分布、近 7 日复习趋势
- **荣誉墙** —— 已斩除错题的陈列室
- **连续打卡** —— 头部火焰标识，断签会变成 🥶
- **数据备份** —— 导出 / 导入 JSON（浏览器清缓存会丢数据，请定期导出）

---

## 使用

```bash
# 无需安装，直接双击打开
index.html
```

或者用浏览器打开即可。首次启动会自带 3 条示例错题（数学 / 英语 / 电路），方便立刻上手试玩。

> ⚠️ **数据说明**：数据保存在浏览器的 `localStorage`，**不会上传到任何服务器**，但**换浏览器、换电脑、清缓存都会丢失**。重要的错题请定期点「导出备份 JSON」。

---

## 技术

- 原生 HTML + CSS + JavaScript，**零框架、零依赖、零构建**
- 存储：`localStorage`
- 所有图表（条形图 / 趋势柱）为手写 DOM + CSS，不引第三方图表库
- 单文件约 1000 行，可直接放进任何静态托管（GitHub Pages / Vercel / 本地）

```js
  lastAt: '2026-11-01',

  killed: false, killedAt: null,
  history: [{ d: '2026-11-01', r: 'master' }]
}
```
